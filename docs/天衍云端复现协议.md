# QuKerNet股票任务：云端复现协议 v2

协议日期：2026-11-10。分类为主线，连续收益回归为扩展。正式计算位置为天衍云仿真机；无影执行经典部分与独立小规模校验。实现与执行状态见云模块README及实测报告。

## 研究对象与来源

依据L001《Neural Auto-designer for Enhanced Quantum Kernels》的[ICLR 2024正式版](https://proceedings.iclr.cc/paper_files/paper/2024/file/4d9944ab3330fe6af8efb9260aa9f307-Paper-Conference.pdf)及作者代码固定提交`c9948606145eb85c2bf53f27acebaf5a071a3fa7`。保持线路生成、KTA标签、神经评分器、筛选、多配置微调、下游评价的完整链条。股票任务、时间切分、连续收益KRR、有限shots和36比特属于明确标注的迁移或扩展。

论文的精确模拟使用PennyLane等软件；已核原文没有把它归为腾讯量子平台计算。KTA是核与任务标签的对齐程度，准确率是下游分类表现，不能互相代替。

## 数据与时间

使用冻结20股2019—2024年快照；SHA256、版本与私有路径在仓库外记录。2025封存。特征在收盘后可得，标签为`open[t+6]/open[t+1]-1`，分类取是否大于0。每季度前252日分为168日训练、84日验证；按标签真实结束时间净化边界。仅训练样本拟合mRMR、缩放和标签标准化。

80项量价特征最长回看120日。训练内选择40项非退化特征；不复制列补足维度。角度变换沿用中位数/IQR：`pi * clip((x-median)/IQR,-3,3)/3`。恒定列和重复列留质量记录。原始价D0只支持预测诊断，不能解释为总回报或策略净收益。

先在168/84日的原始日历上按标签成熟净化边界，再按合格日历分箱；冻结窗口得到162/78个可用日期。T/V样本各16、32或150时，分别划分8、16、15个日期箱，每箱选2、2或10只证券。取箱内合格日期的上中位数，证券按累计覆盖最少、固定随机并列、证券标识排序。评价区使用季度五交易日网格，标签须在季度内成熟。

## 执行契约

`tianyan_sa`的指定态输出须先证明返回语义、精度和计费；`tianyan_sw`提供有限读数路线；`tianyan_swn`仅在噪声位置和参数语义核实后使用。MCP进程内模拟、SDK本地模拟与云任务分别记录。

每次提交须满足当前账户、接口、后端的免费且不扣真机额度证据。凭据只由运行进程安全输入，不写入课程、配置快照或日志。已获授权的实验室数据可发送天衍，但该授权不等于公开原始数据。

新增全局上限：72小时、100亿请求shots、8000万概率线路，先到即停止新增提交。预检最多50条线路/2万shots，包含在总账内。单批最多20，实际还须符合已核服务端限制。失败和未知提交占额度；无自动重试、无隐式换后端。单任务观察最多300秒；未知状态停止新提交，只查询原ID。客户端超时不代表后台取消。

## 方法与统计

分类使用同类/异类目标矩阵KTA与SVC(C=1)；回归使用中心化回归对齐和平均损失KRR。量子核两端共享参数，参数移位逐门出现计算核概率导数，再链式求KTA梯度；不直接对归一化KTA作一次移位。全部入围×配置终点进入开发验证，后续季度仅评价。

精确核异常停止，不能用nearestPD掩盖。有限测量拟合采用训练谱截断及一致交叉核延拓；KTA及微调使用原始估计核。记录修正幅度。原始逐次读数与由概率换算的counts分开，后者不构成原始抽样证据。

优先顺序：接口预检→8比特分类先导/核心→20与36比特→其他窗口与回归→消融/噪声/扩大配额。规模按4、8、16、20、24、30、36逐级验证；零命中不记为精确零。不可辨认也是结果。

## 历史与新实验

旧本地实验文件保持原版本，旧协议中的禁止云传输适用于其历史运行。v2按新的用户授权执行，记录其独立边界。旧全振幅30比特成功、36比特失败且原因未知，均不能作为v2金融搜索已成功的证据。原论文20比特附录实验也不能写成36比特实验。
