# 课程可行性实测摘要

2026-11-09完成第一轮验证。现有CPU资源已支持课程的小规模数据诊断、核模型与有限测量计算；完整交易项目与新增天衍云端验收仍有待补齐的证据。

| 项目 | 已完成的证据 | 边界 |
|---|---|---|
| 数值正确性 | 本地170项、远端170项量子检查；42项核模型检查通过 | 解析输入上的独立数值一致性，不是任意线路证明 |
| 解析状态向量 | 4/8/12/16/20比特，深度1/2/4，每点3次，两地各45次成功 | 单输入态；不等于高比特大样本核同时跑通 |
| 核与拟合 | 4候选，训练/评价各128、256、512、1024，每点3次成功 | 使用4比特解析输入，含谱修正与经典显式对照 |
| 数据与预测链 | 固定开发片段的D0原始价格诊断已运行 | 私有数据和金融指标不在公开仓库；不是正式总回报回测 |
| 波动预测 | 已保留实际运行、缺口与模型拒绝记录 | D0代理与初始化口径须与正式协议继续对齐 |
| 数据接口 | AkShare固定日线/复权请求返回并完成字段对账 | 同一上游不是独立来源；yfinance本次空表并报告限流 |
| 天衍 | 12条解析线路数值及Cqlib1.3.11离线解析通过 | 新云端提交0；不扣真机额度的前置证据尚缺 |

当前实数4比特核具有最多136维的精确经典特征表示，课程已加入匹配的经典对照。有限shots通过精确概率后的二项重采样研究；名义测量预算不能当作真实云端执行次数或收费。

执行入口见[验证脚本说明](../experiments/feasibility/README.md)；教学入口为[解析量子核与有限测量Notebook](../notebooks/C08_C09_解析量子核与有限测量.ipynb)。Notebook三个代码单元由新Python进程核验，完整Jupyter内核环境仍待独立重建验收。

本轮使用Python3.12.13的独立CPU环境，实际包清单见[运行版本记录](../experiments/feasibility/requirements-observed-py312.txt)。这是成功运行环境的版本记录，不等于已经完成跨平台安装验证或含全部文件哈希的依赖锁。

优先补齐公司行动、成交与费用账本，以及GARCH初值定义；2025测试继续封存。保持4比特与小候选池作为核心，真实交易回测、共享测量、自适应分配、GPU、云端批量核和教学学习效果分别验收。
