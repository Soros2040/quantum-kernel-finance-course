# 课程建设与贡献说明

## 1. 课程版本与建设阶段

当前阶段交付课程设计：学习路线、11章教学规格、项目协议、来源记录、教学对标和环境方案。完整讲义、Notebook、公开数据样例及实测报告分阶段建设。

| 阶段 | 工作 | 进入下一阶段的条件 |
|---|---|---|
| S1 课程设计 | README、大纲、来源、协议与建设规范 | 课时、参数、引用与链接一致，公开内容审查通过 |
| S2 金融基础 | C01—C06讲义、真实数据作业与经典流程 | 标签时间、特征可得性、基线、账本及成本测试通过 |
| S3 量子核心 | C07—C09讲义、解析例与有限测量实验 | 手算一致、核构造正确、预算和随机性可追溯 |
| S4 综合复现 | C10—C11、独立复跑与综合报告 | 新环境可复现，证据与结论匹配，发布资料许可明确 |

每章状态只使用“设计完成”“材料制作中”“已通过章内验证”“已完成独立复现”四种描述。阶段状态不由文件数量或截图数量决定。参数变化更新[数据与实验协议](数据与实验协议.md)，受影响Notebook、作业和来源映射同步修改。

## 2. 单章交付模板

每章包含以下可检查内容：

1. 一个明确的金融问题及其信息时间轴。
2. 学习目标、先修、讲授/指导实验课时和预计课外时间。
3. 必要概念与推导，说明假设、符号、量纲和适用范围。
4. 一个能手算核对的例子，金融例子附真实数据来源和记录定位。
5. Notebook的输入、处理步骤、输出和失败信息。
6. 至少一道独立作业，给出验收标准与常见错误诊断。
7. 指标解释、可支持结论、反例或不足，以及原文定位。

数学推导重点服务决策：例如KRR求解服务模型训练；标签时间轴服务防泄漏；协方差服务判断损失差；资源公式服务确定可执行实验规模。

## 3. 作业与项目评价

综合项目建议评分：问题与数据时间边界25%、经典对照与金融评价25%、量子定义与资源账本20%、复现和测试20%、证据与结论10%。收益为负或量子模型不占优不扣结果方向分；错误数据时间、遗漏重要成本、把未运行结果写成实测，须修正后重新提交。

Notebook需从新内核顺序运行。提交图表同时提交生成所需配置与指标表；测试应验证实际内容、数学性质或金融时间关系。用截图展示程序结束不构成结果正确的证据。

源文件、公开运行清单、作业答案和模型输出分别标明版本。完整私有数据无法公开时，给出获取要求、字段字典、质量报告和数据标识，说明独立复现受到的限制。

## 4. 贡献与勘误

贡献可包括讲义、公式核对、真实数据适配、Notebook、作业、测试及文献核验。提交说明应包含：解决的问题、影响章节、依据来源、验证方式和剩余限制。

勘误按以下信息组织：

- 课程版本、文件、节标题或Notebook单元编号；
- 当前表述或最小问题案例；
- 正确关系或建议修改，附原文页/节/公式或可复核计算；
- 是否影响已有实验和结论，是否需要重跑。

网络仓库发布后可采用Issue和Pull Request承载这些记录；本地建设阶段使用同样字段的文件记录。维护者审核后更新版本说明，必要时撤回受影响的指标结论并重跑。对数据许可或隐私问题仅提交描述和最小必要字段，不上传整份私有数据。

## 5. 来源与内容标签

课程统一区分：

| 标签 | 意义 |
|---|---|
| 已知理论 | 已核来源支持的定义或结论，保留假设 |
| 文献报告 | 来源作者报告的结果，注明实验条件与本课程复核程度 |
| 本课程推导 | 基于显式假设自行推导，展示关键步骤 |
| 教学构造 | 可手算的数学或量子例子，不作为市场事实 |
| 研究假设 | 需要证据检验的判断 |
| 待运行实验 | 已定义协议但尚未运行 |
| 实测结果 | 有数据标识、代码/环境、配置、日志和指标记录的实际运行 |

来源编号在[文献与阅读记录](../references/文献与阅读记录.csv)统一维护。书籍按书名、版次与页码定位；论文区分出版版本和预印本；代码使用固定提交及行号，Notebook单元编号注明是否包含Markdown单元。仅核摘要不能支持完整方法或实验结论。

## 6. 公开发布检查

发布一个课程版本前，检查：

- README如实显示可用章节、环境、数据和未完成内容。
- 本地链接可用；来源编号存在；课时合计与正文一致。
- 发布的文档、表格和Notebook输出无私人路径、认证信息或受限数据。
- 原创与第三方内容范围、署名和适用许可明确，数据样例具有分发依据。
- 安装和最小实验在独立环境复现；结果表可追溯到指定运行。
- 研究报告对方法无收益、统计不确定及适用范围提供完整解释。

本地建设和公开发布是分别记录的事件。课程内容在本地准备完成后，再由维护者核定发布版本、平台与许可。
