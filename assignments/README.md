## 推导与手算的最低要求

KRR必须从目标函数走到系数方程，清楚写出和损失λ与均值损失nλ；波动题必须说明代理的条件无偏假设及QLIKE的正值条件；量子核题必须说明测量设置；误差传播题必须包含训练核引起的重新拟合。共享协方差题要求给出读数复用的物理条件，PSD修正题要求讨论非光滑边界。

金融手算需提交原始行标识、时间口径和中间步骤；仅有代码截图或最终数字不能验收。纯构造题可采用大纲给定的矩阵、量子态和代数误差，必须标注为解析构造。

## 评分建议与硬性门槛

日常作业A01–A10合计占课程成绩60%，每项6%；综合作业A11占40%。日常作业按问题与假设20%、计算或推导30%、评价与证据30%、可复核表达20%评分。A11按问题与数据25%、经典金融基线25%、量子方法与成本20%、复现与测试20%、证据与结论10%评分，与课程建设与贡献说明一致。没有运行结果的设计部分按其真实状态评分，不把计划完成度折算成实验性能。

以下问题须修复后才能通过相应阶段：数据来源或授权不明；训练使用未来信息；测试用于调参；方差／标准差或正则约定混用；交易账本与净值不一致；将模拟读数伪称设备结果；隐去失败和预算；使用未获准的共享测量假设；编造数据或结果。

## 四个阶段的验收

1. **金融接口门槛：A01–A03。** 问题、来源、时间边界和特征都能被独立解释与检查。
2. **经典评价门槛：A04–A06。** 基线可复算，收益和波动分开评价，账本与净值一致。
3. **量子诊断门槛：A07–A09。** 解析测量正确，固定候选池和预算明确，重复选择结果有真实记录。
4. **研究交付门槛：A10–A11。** 结论有定位，封存测试合规使用，负结果和未知项完整，第三方可沿入口重建关键表。

## 同行复核问题

复核者至少回答：能否确认某条预测只使用当时信息；能否从原始输入重算一个结果；最强经典对照是什么；量子部分替换了哪一步；预算是否完整；哪一个结果会推翻当前主张；没有原始数据权限时能否验证接口和推导。

报告建议依次写问题、相关研究、数据与协议、方法、真实结果、稳健性与失败、资源、局限、复现说明。复用开源材料时注明来源和许可；公开内容与受限数据分开管理。
