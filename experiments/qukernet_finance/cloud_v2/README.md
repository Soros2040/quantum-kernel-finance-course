# QuKerNet股票任务：云端版本

这是课程进阶复现模块。分类为主线，回归为扩展；KTA、验证准确率、后续季度准确率分别记录。依据作者代码固定提交 `c9948606145eb85c2bf53f27acebaf5a071a3fa7`，迁移差异见[实验协议](../../../docs/天衍云端复现协议.md)。

## 模块与状态

|模块|内容|验证范围|
|---|---|---|
|features80 / data80|80项特征、成熟日期净化、训练内mRMR、私有快照|合成单元检查与冻结真实快照准备|
|circuits|布局、40特征重复编码、QCIS、双端参数移位|小线路独立态计算和有限差分|
|search / experiments|KTA、MLP、top-k、全部微调终点、SVC/KRR、恢复|离线模拟接口完整链；真实云执行另记|
|cloud / ledger / preflight|一次提交、预算预留、状态、原始读数校验|模拟错误场景与实接口预检分别留证|
|client_entry|显式Linux运行入口|默认不执行；凭据只在运行进程内|
|protocols.json|先导、核心、高比特和消融配置|登记不表示所有消融已实现或运行|

`sa`精确输出及`swn`噪声语义仍需独立验证，当前适配器走`sw`有限测量路线。没有把本地模拟作为云端主结果。

## 学习与运行

先运行[六份教学Notebook](../../../notebooks/qukernet_cloud_v2/README.md)，默认不访问云服务、不读取私有金融数据。实际数据通过仓库外的冻结快照接入；公开输出仅含获准汇总。

从本模块父目录运行：

```text
python -B -m unittest discover -s cloud_v2/tests -p "test_*.py" -v
python -B -m cloud_v2.experiments --help
python -B -m cloud_v2.client_entry --help
```

`requirements.txt`是目标环境；[environment-linux-actual.lock.txt](environment-linux-actual.lock.txt)记录独立Linux/Python 3.11实际生产环境，76项测试全部通过、SDK语法检查6项通过，依赖检查通过。先从PyTorch官方CPU wheel源安装`torch==2.5.1+cpu`，再按锁文件安装其他依赖；新机器仍需重做验收。运行时保存Python、全部依赖、代码哈希、数据哈希、线路哈希、配置哈希和账本。云运行必须显式`--execute`，先检查账户与费用证据，再接受隐藏输入或进程环境变量中的凭据。Notebook不自动提交。

## 账户和资源边界

2026-11-10已登录官方账户页显示：全振幅免费赠送套餐不限时长、适用36比特，旧全振幅任务明确记入该套餐；真机有独立的600秒套餐。这是账户套餐与扣费归属证据，不是通过新任务观察余额作出的猜测。

|后端|平台标称比特数|当前账户套餐适用比特数|
|---|---:|---:|
|全振幅 sw|36|36|
|稳定子 s|5000|15|

权限和套餐会变化，提交前仍检查当前状态。不同后端的比特数不代表相同计算任务。历史sw30比特成功、36比特失败原因未知，历史稳定子64比特因账户权限被拒；新运行记录见[证据目录](../../../reports/qukernet_cloud_v2/README.md)。
