# 课程可行性实验

本目录提供可检查的数值实现、资源基准及独立诊断入口。已运行范围见[课程可行性实测摘要](../../docs/课程可行性实测摘要.md)，环境版本见[环境与复现说明](../../docs/环境与复现说明.md)。正式数据与实验参数仍以[课程协议](../../docs/数据与实验协议.md)为准。

## 已完成的范围

- 本地与独立Linux环境分别完成170项量子检查、45次状态基准，测试至20比特、深度4。
- Linux环境完成42项核/模型检查；训练样本128、256、512、1024，每档3次、共12次模型基准成功。
- 20股原始价D0诊断跑通12个开发季度；有限采样按32、128、512 shots各完成20次重复。D0不使用2025数据，不是正式实验A/B或策略收益验收。
- 12条解析线路已通过SDK离线解析。本轮云提交0；没有证实免费或不扣真机额度。
- GARCH真实数据运行状态单列于实测摘要，不以依赖安装或其他检查通过替代。

公开说明不提供受限数据的证券、私有损失或候选选择频率。以上“成功”指指定入口完成及其断言通过，不证明数据已满足全部金融准入条件、模型具有投资价值或量子计算优势。

## 模块与执行边界

| 文件 | 输入与功能 | 主要边界 |
|---|---|---|
| quantum_core.py | NumPy实现RY/CNOT态、保真度核、实密度特征 | q0为基索引最高位；不缩放金融数据，不联网 |
| kernel_models.py | 训练缩放、相容谱扩展、mean-loss KRR与显式ridge | 使用nλ；训练映射用于评价；谱阈值处不保证可微 |
| verify_quantum.py | 解析输入；小酉矩阵、逆序重叠及特征核检查 | 小矩阵参考仅用于小比特数 |
| verify_models.py | 解析输入；核/显式ridge、谱映射及退化检查 | 数值一致性不等于金融验证 |
| benchmark_quantum.py | 单样本态性能；每点独立子进程 | 不构造大酉矩阵；不测试核拟合 |
| benchmark_models.py | 四候选训练与同规模评价；分阶段计时 | 顺序处理候选；包含核与显式特征两条计算，不能把总时间当单一路线 |
| data_access.py | 数据盘点、准入准备及核对 | 输入只读；输出单独指定；字段存在不等于准入通过 |
| run_diagnostics.py | D0原始价开发期预测与理想采样诊断 | 拒绝2025及以后数据；不执行交易账本 |
| run_volatility.py | 独立波动目标、基线和诊断 | 单独核对代理、时间轴与实际运行状态 |
| probe_interfaces.py | 独立公开接口探测 | 可能联网；接口成功不证明金融口径或分发许可 |
| prepare_cloud.py | 标准库生成12条解析QCIS及待提交清单 | 离线准备；不读取凭据、不登录、不提交 |
| safe_io.py | 输出根与路径保护 | 不代替数据许可和操作系统权限 |
| bounded_run.py | Linux受限执行与资源记录 | 平台专用；超时与内存定义随执行记录解释 |

## 运行解析检查和资源基准

以下命令从课程根目录运行。PRIVATE_OUTPUT 是占位符，应替换为**仓库外、本地可写的私有输出目录**；不要使用共享输入目录。示例不提供依赖安装步骤，先按环境说明准备并检查已有环境。

~~~text
python experiments/feasibility/verify_quantum.py --output "PRIVATE_OUTPUT/quantum/verification.json"
python experiments/feasibility/verify_models.py --output "PRIVATE_OUTPUT/models/verification.json"
python experiments/feasibility/benchmark_quantum.py --output-dir "PRIVATE_OUTPUT/state_benchmark"
python experiments/feasibility/benchmark_models.py --output-dir "PRIVATE_OUTPUT/model_benchmark"
~~~

两个基准默认每点3次、最多4个数值库线程、16 GiB进程内存约束和单工作进程300秒上限。任一结果非成功时先保存部分记录，再退出，后续规模不会自动启动。它们输出逐次JSON/CSV及实际源文件哈希；旧版本的成功运行保留原哈希，不因后续代码修改被重新标为实测。

态基准计时不含解释器启动和NumPy导入；进程耗时另记。模型基准分开记录态、核、谱映射、对偶求解、密度特征与匹配显式ridge。RSS包含解释器与工作区，不能只用理论状态数组字节数替代峰值。

学习者也可先打开[最小解析Notebook](../../notebooks/C08_C09_解析量子核与有限测量.ipynb)。其3个代码单元已分别在新进程验证；当前不声明完整Jupyter环境验收通过。

## D0诊断入口与金融边界

INPUT_CSV 应替换为已获准使用、经过字段核查的日线表，包含 symbol、date、open、close、volume；日期必须早于2025。CALENDAR_CSV 应替换为具有 date 列及来源记录的市场交易日历。缺失正式交易日历时，程序的观测日期并集不能被称为已认证的交易所日历。

~~~text
python experiments/feasibility/run_diagnostics.py --input "INPUT_CSV" --calendar "CALENDAR_CSV" --output "PRIVATE_OUTPUT/d0"
~~~

运行前核对数据权限和输出目录，并按资源计划提供受控执行环境。D0的标签使用原始开盘价，训练按已实现标签和季度截止过滤；评价仅属于开发期诊断。未来标签有效性筛选用于离线评分，不能解释为当时可交易资格。G4总回报准入未过时，不生成“正式总回报实验已完成”或“策略已经验证”的结论。

有限测量部分用2022的有限采样独立校准公共λ，以2024固定样本作诊断。候选选择函数只接收采样矩阵、标签和固定λ；精确损失用于事后比较。这是函数接口层面的访问约束，不是进程级安全隔离。

默认64训练、40评价、四候选每轮需要18,304个估计元素。三档shots各20次加独立校准，共248,348,672个**名义shots**；程序以二项计数实现，实际云shots为0。该数字不是云任务数，也不等于本地逐shot状态演化次数。修改规模、预算或重复必须重新核算，不能继续沿用这个总数。

## 保存和解释结果

OutputRoot 检查输出根、目录逃逸和可识别网络共享路径；带输入源约束的入口还阻止输出落入该源。仍须确认真实挂载位置，保持输入原件只读。受限数据及运行结果保存在仓库外，公开Notebook只保留可公开的解析输出。

每次结果应带环境、输入和代码哈希、随机种子、矩阵规模、计时边界、失败记录与预算。报告区分解析构造、理想采样、原始价诊断、正式金融实验和设备结果；不以一种通过替代另一种验收。来源、署名及公开条件遵循[许可与署名](../../docs/许可与署名.md)，本目录不新增第三方许可判断。
