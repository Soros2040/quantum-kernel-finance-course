# 资料与阅读记录

本目录服务于“多股票收益预测与选股—经典核基线—量子核—有限测量可靠性”课程。波动预测作为独立标签与评价任务展开；组合优化仅作应用版图简介。核心课程为 11 章、84 课时，另设 12 课时桥接；1 课时为 45 分钟。

- [文献与阅读记录.csv](文献与阅读记录.csv)：40 条公开书目、文档及源代码记录，包含已读定位、证据边界与待补证。
- [章节资料映射.md](章节资料映射.md)：各章必读段落、阅读产出和验收联系。
- [教学与开源对标.md](../docs/教学与开源对标.md)：固定提交的具体做法与本课程采用方式。

## 阅读状态与版本口径

阅读状态采用四类：

| 状态 | 记录含义 |
| --- | --- |
| 已核对全文相关段落 | 已打开原文并核对“实际已读定位”所列段落；不表示整本书或整篇论文通读。 |
| 仅核摘要或代码 | 仅摘要或源代码层面的证据。是否读完代码见定位；不表示已经运行、得到结果或核验原始实验。 |
| 可见但未读 | 文件或页面可见，尚未用于实质性判断。 |
| 未找到或无访问权限 | 所需内容当前无法核验；不能按标题或其他索引推断其内容。 |

当前公开清单主要保留已经读到相关段落或代码的材料。空的 SHA256 表示未取得该文件字节哈希，不表示零值；Git blob SHA-1、仓库 commit 与文件 SHA256 分别记录，不相互替代。四个课程仓库均固定至已核提交。`arch` 的 `latest` 网址为动态入口，已读文档版本另列，实施时须固定软件版本。

PDF 页从 1 起计数，包含封面；印刷页是纸面显示的页号。没有核实统一偏移时，记录具体页对或仅使用 PDF 页。Notebook 单元序号包含 Markdown 单元，从 1 起计数；行号为固定版本文件的行号。

L 为教材与讲义，R 为开源资料，F 为论文，W 为软件文档。保留稳定编号，未纳入课程的条目不列入清单。

## 选用与补证规则

1. 综述用于建立任务版图和寻找原始研究。具体复杂度保证、优势与实证结果须追溯相应的一手论文。
2. 理论、代码阅读和运行结果分别记账。本阶段没有运行这些仓库示例，也没有据此形成课程实测结论。
3. 教材页码只是定位入口。核岭回归须明确“求和损失”或“平均损失”规范；测量共享须说明态、测量设置与后处理；金融数据须说明时间可得性与许可。
4. 文献公开可访问、代码开源、行情可下载是三种不同权限。课程只提供链接、原创解释与练习；不附未获授权的教材扫描件、论文全文或行情数据。
5. 当前主要补证包括：部分中文教材版权页/版次，L17 印刷 31 页之后的完整本，具体行情源的再分发授权与时间口径，以及实施时的软件环境和接口行为。F08/F09 的公开原文链接已读，但未在本表记录文件字节哈希。

第三方材料许可见 CSV 和对标文档。改编带有非商业、禁止演绎或相同方式共享限制的材料时，必须分别遵守其条款；不能由课程自身的拟议许可证覆盖。
