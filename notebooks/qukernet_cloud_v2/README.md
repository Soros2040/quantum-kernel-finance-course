# 六节云端复现教学实验

按顺序学习；每节均有问题、代码、验收与作业。默认关闭云执行，公开Notebook只读字段字典、解析构造与已获准的历史汇总。

1. [数据与80特征](01_数据与80特征.ipynb)：标签成熟、训练内选择、单位一致性。
2. [天衍接口与提交条件](02_天衍接口与提交条件.ipynb)：计算位置、账户证据、位序、未知任务。
3. [完整搜索与微调](03_完整搜索与微调.ipynb)：KTA、神经评分器、全部配置终点、双端导数。
4. [对照消融与历史证据](04_对照消融与历史证据.ipynb)：同配额比较及KTA与准确率的区别。
5. [有限测量与噪声](05_有限测量与噪声.ipynb)：零命中、选择稳定性、遗憾、器件噪声。
6. [规模资源与研究边界](06_规模资源与研究边界.ipynb)：平台标称、账户权限、实测范围与资源推算。

2026-11-10六份Notebook共18个代码单元已在独立Python 3.12环境顺序执行通过；这项检查未调用云服务。真实生产客户端在Linux/Python 3.11独立验证，环境及运行结果分别记录。

Notebook不保存真实行情、角度、核矩阵、模型参数或逐样本预测。云执行请使用[模块入口](../../experiments/qukernet_finance/cloud_v2/README.md)，不要把密钥写入单元格。
