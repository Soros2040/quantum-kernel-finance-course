## 当前可运行示例

[C08—C09：解析量子核与有限测量](C08_C09_解析量子核与有限测量.ipynb)使用明确标注的解析输入与数学标签，包含3个自包含代码单元：

1. 4比特理想实振幅态的保真度核，与136维实对称密度特征核一致。
2. 固定解析例的有限二项采样可产生不定训练核，并列明名义shots。
3. 训练谱修正与评价交叉核相容，平均损失KRR的原—对偶预测一致。

三个单元已分别在独立Python新进程中运行，保存的输出仅含解析数值。基础路径只依赖NumPy；已有SciPy时，最后一个单元额外比较数值模块。当前保存输出中该项SciPy模块比较明确标为未运行。此次验证没有覆盖JupyterLab安装、内核注册、干净内核完整执行或环境二次重建。

本示例不读取行情、账户或网络资源，不生成股票预测或交易收益。其他数值检查与资源基准通过[可行性实验脚本](../experiments/feasibility/README.md)执行；它们的运行状态不能替代各章Notebook验收。

## 每个Notebook的共同结构

开头记录：研究问题、依赖章节、协议版本／哈希、数据准入状态、输入文件哈希、软件环境、随机性来源、预计资源及输出位置。随后依次为输入检查、手算／解析核查、计算、结果表、评价与局限。结果表保留日期、证券或候选标识，不能只有一张汇总图。

所有可能影响结论的数值参数从协议配置读取。分析展示可以减少行数，计算不能因展示筛选而改变样本。随机种子不是独立性或物理共享的证明；测量实验须记录采样模型和各动作的读数来源。

## 运行门槛

- 数据准入未通过：正式金融单元停止并输出“待提供 fixture”及缺件说明；纯数学和解析量子单元可独立运行。另立范围的D0原始价诊断须保留该标签，不能计作正式总回报或回测验收。
- 时间检查未通过：停止后续拟合与回测，保留失败证据；不静默随机切分。
- 经典基线与账本未通过：量子结果可作技术调试，不能形成金融优胜结论。
- 核管线未通过：检查训练／验证核块、正则约定及PSD政策；不得依靠事后换政策消除失败。
- 封存测试：按协议规定的开启、登记和复用规则执行；开发单元默认不读取。

## 证据与复现要求

保存逐次运行状态、耗时、失败信息、配置和输入指纹。原始采样读数与派生核、预测、损失分层保存；执行预算包括协议规定的所有动作。精确概率、理想采样、含噪仿真和设备结果分别标记。

完整Notebook验收仍要求从干净内核按顺序运行，不能依赖隐藏变量。当前逐代码单元的新进程验证是已完成的数值检查范围。删去展示输出后也应能由获准输入重建结果；若数据许可限制共享，公开读取接口、字段字典和获取说明，而不捏造替代金融历史。大文件、受限数据和凭据不进入公开Notebook。

运行状态采用“待建设／待数据／可运行未实测／已实测／失败待修复”，并附检查范围。当前解析示例标为“代码单元新进程已实测”；其他计划单元尚不能据此标为已实测。正式总回报实验、策略账本与封存测试仍须独立验收。
