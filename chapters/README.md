## 共同写作结构

每章依次包含：金融问题与学习目标；先修诊断；真实历史案例及来源；符号与时间线；逐步公式推导；手算题；对应Notebook输入输出；结果阅读方法；验收与自测；精确来源定位；局限与进阶阅读。公式须说明变量、单位、假设和它如何影响一个计算或评价选择。

推导不能只给结论：KRR须展开目标与求导并说明和／均值损失的正则换算；QLIKE须区分代理与潜在方差；测量传播须包含训练核、重新拟合和验证核；共享协方差须说明实际共同读数来源。PSD谱修正的非光滑位置与适用限制必须保留。

## 案例与实验边界

金融案例仅取通过准入的真实历史fixture。引用数据时给出来源、授权范围、证券与时间范围、价格口径和文件哈希；准入未通过则写“待提供 fixture”，保持题目和接口，暂不填写计算结果。二维矩阵、单比特态等可作解析构造例，并明确其不是金融实测。

实验参数只引用[数据与实验协议](../docs/数据与实验协议.md)。讲义可以解释参数的含义和影响，不能复制一套逐渐失配的默认配置。年度实验A按协议使用精确核；诊断B的精确核仅用于事后参照，并与A的精确调参隔离。

## 建设与审阅检查

1. 先完成C01–C06的金融数据、预测和交易接口，再衔接C07–C09；量子模块不得另建一套评价目标。
2. 数学内容由解析题或独立推导核查；金融数字必须能回到获准原始记录。
3. 每条经验结论链接真实运行及配置；未运行内容采用实验设计语气。
4. 引文同时注明版本、PDF页和印刷页／节／式；综述转述与原研究核读分开。
5. 课程采用可复用的“输入—计算—输出—验收—限制”组织；参考项目的代码、数据与许可证逐项核对后再复用。

章节只有在讲义完成、对应练习可用、来源核对和独立审阅完成后才改为“已建设”；Notebook是否实测另按其运行证据登记。
