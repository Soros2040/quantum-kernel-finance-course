# 量化投资与量子核

从真实股票数据出发，学习投资信号、收益预测与选股，建立经典模型和量子核模型的对照，并检验有限测量是否改变候选核的选择。

本课程面向会基础 Python、希望开展可复核投资研究的学习者。金融问题决定数据、标签、时间边界和评价方法；量子部分解释数据如何编码、核如何测量、模型怎样拟合，以及这些步骤实际消耗什么资源。

## 学完能够做什么

- 为多股票预测定义标签、信息可得时间、时间切分和封存测试。
- 建立经典收益预测、波动预测与扣费回测，解释预测指标和投资表现的差别。
- 手算小规模量子态与测量概率，实现保真度核和下游核岭回归。
- 在固定候选池中检验有限 shots 引起的损失差变化、选择稳定性和失选代价。
- 提交包含经典对照、资源账本、来源定位和证据边界的复现报告。

负结果同样是合格研究成果：评价依据是问题定义、验证纪律、复现能力和结论与证据的一致性。

## 学习路线

**投资问题 → 真实数据与时间轴 → 特征 → 经典收益与波动预测 → 持仓和回测 → 量子基础 → 量子核 → 有限测量诊断 → 综合报告。**

| 阶段 | 章节 | 课时 |
|---|---|---:|
| 金融数据、模型与评价 | C01—C06 | 42 |
| 量子基础、核方法与可靠性 | C07—C09 | 26 |
| 证据审计与综合项目 | C10—C11 | 16 |
| 核心合计 | C01—C11 | 84 |

每课时45分钟，含讲授与指导实验；课外阅读及项目整理约36小时。数学诊断后可选最多12课时桥接。变分模型、高频波动、风险定价和动态对冲列为进阶模块。

## 综合项目

1. **真实历史上的收益预测与选股**：比较动量、岭回归、RBF KRR与量子核KRR，报告预测、投资及计算三类结果。
2. **有限测量可靠性诊断**：固定数据与候选线路，重复采样，检查损失差、选择频率和失选代价。

两项成果共享金融问题，但各自具有独立的实验范围。完整参数、数据准入和解释边界以[数据与实验协议](docs/数据与实验协议.md)为准。

## 如何开始

1. 阅读[课程大纲](课程大纲.md)，完成数学桥接诊断并确定学习顺序。
2. 阅读[数据与实验协议](docs/数据与实验协议.md)，了解真实数据需要满足哪些条件。
3. 查阅[环境与复现说明](docs/环境与复现说明.md)。已有Python 3.12数值运行记录；Python 3.11目标环境、第二次独立重建及完整Jupyter内核流程仍待验。
4. 从[解析量子核与有限测量示例](notebooks/C08_C09_解析量子核与有限测量.ipynb)开始，再按[可行性实验入口](experiments/feasibility/README.md)核对脚本、资源限制与输出位置。
5. 按[章节资料映射](references/章节资料映射.md)选读原文。金融练习须取得符合准入条件的真实数据，不用解析构造代替金融验收。
